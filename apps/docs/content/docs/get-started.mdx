## Prerequisites

[`issue-graph`](https://www.npmjs.com/package/issue-graph) is available on npm with a working CLI and library. No source checkout is required.

You need:

- Node.js 20 or later, with npm and npx.
- [GitHub CLI](https://cli.github.com) (`gh`) on your `PATH` for GitHub queries.
- GitHub authentication with access to the repositories you query.

## Install from npm

Inspect the CLI without installing it globally:

```bash
npx issue-graph@latest --help
```

npx downloads the package when needed and runs its executable. Help does not require GitHub authentication. For repeated use and the `issue-graph` command used throughout these docs:

```bash
npm install --global issue-graph@latest
issue-graph --help
```

To use npx instead, replace `issue-graph` at the start of a workflow command with `npx issue-graph@latest`. Installing the CLI does not automatically install an agent skill; see [Agents and skills](/docs/agents).

## Authenticate GitHub

```bash
gh auth login
gh auth status
```

The CLI uses the credentials available to `gh`. Private repositories and cross-repository references still require permission, including any organization SSO authorization. Do not paste tokens into command examples or commit them to configuration. The source repository remains **INTERNAL**, but its access restrictions do not prevent installing the public npm package.

## Get your first real result

Inspect the neighborhood of [agent-browser issue #1113](https://github.com/vercel-labs/agent-browser/issues/1113), a report about orphaned Chrome processes:

```bash
issue-graph 1113 --repo vercel-labs/agent-browser --depth 1 --max-nodes 12 --no-snapshot
```

The equivalent URL form is:

```bash
issue-graph https://github.com/vercel-labs/agent-browser/issues/1113 --depth 1 --max-nodes 12 --no-snapshot
```

Graph mode prints Markdown, even in a pipe. The bounded example captured on 2026-09-22 contains five nodes, all in `vercel-labs/agent-browser`:

| Captured node | State at capture | What to inspect |
| --- | --- | --- |
| [Issue #1113](https://github.com/vercel-labs/agent-browser/issues/1113) | CLOSED | The original orphaned Chrome report |
| [PR #1137](https://github.com/vercel-labs/agent-browser/pull/1137) | MERGED | The fix with a closing link to #1113 |
| [Issue #1148](https://github.com/vercel-labs/agent-browser/issues/1148) | CLOSED | A regression report referencing that fix |
| [Issue #1371](https://github.com/vercel-labs/agent-browser/issues/1371) | OPEN | A high-CPU Chrome Helper follow-up |
| [Issue #1607](https://github.com/vercel-labs/agent-browser/issues/1607) | OPEN | A macOS GUI Chrome launch follow-up |

This is not a live feed or complete history. The capture includes every fetched node but leaves 19 references beyond the depth boundary and omits 22 edges to unfetched references from the displayed graph. States were read during a capture window, not atomically. Re-running the command queries current GitHub evidence and may return different results.

The merged fix and closed seed do not establish that the open follow-ups are resolved. Inspect their scope and current behavior before proposing any action.

Before acting, inspect failed or unfetched nodes, the node-cap section, and hubs not expanded. `--depth 1` bounds recursion and `--max-nodes 12` limits fetched nodes; `--no-snapshot` avoids saving a new history file. None of these makes the graph exhaustive.

## Save an explorer when you want a file

```bash
issue-graph 1113 --repo vercel-labs/agent-browser --depth 1 --max-nodes 12 --no-snapshot --json graph.json --html graph.html
```

Open `graph.html` in your browser. These are explicit local writes even with `--no-snapshot`. Inspect their contents before sharing them, especially after querying private repositories.

## Update an npm installation

After reviewing the release you want to use:

```bash
npm install --global issue-graph@latest
issue-graph --help
```

`@latest` selects the latest published release, not unreleased source capabilities. Check your installed command's help before relying on features described by a newer source checkout.

## Optional source development

Source development requires access to the **INTERNAL** `vercel-labs/issue-graph` repository. Public npm installation does not grant that access. Contributors use pnpm and Node.js 20.19.x or 22.12+; Node.js 24 is recommended:

```bash
gh repo clone vercel-labs/issue-graph
cd issue-graph
pnpm install --frozen-lockfile
pnpm build
node dist/bin.js --help
```

A source build can contain unreleased features. It is not required to use the published CLI.

If the installed command is unavailable, check your `PATH` and npm global installation, or use the npx command above. For GitHub access errors, check `gh auth status` and repository permissions. An inaccessible reference does not mean the work is closed or absent.
