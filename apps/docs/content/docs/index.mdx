## Start with the work in front of you

`issue-graph` is a CLI and library for understanding related GitHub work before you implement, review, or clean up a backlog. It follows text mentions and structural links, retains attribution where available, and derives triage signals from the evidence it can read.

Crawling, classification, status aggregation, and queue ordering require no model. Root-cause clustering is a separate, optional agent step.

## Install before running examples

[`issue-graph`](https://www.npmjs.com/package/issue-graph) is published on npm with the CLI and library. Try the latest published CLI without a global installation:

```bash
npx issue-graph@latest --help
```

For the installed `issue-graph` command used throughout these docs, run `npm install --global issue-graph@latest`. Node.js 20 or later and authenticated GitHub CLI access are required for GitHub queries. The source repository remains **INTERNAL**; installing the public package does not require or grant source access.

Follow [Get started](/docs/get-started) for prerequisites, authentication, and a first graph around public [agent-browser issue #1113](https://github.com/vercel-labs/agent-browser/issues/1113):

```bash
issue-graph 1113 --repo vercel-labs/agent-browser --depth 1 --max-nodes 12 --no-snapshot
```

The bounded capture from 2026-09-22 contains five nodes, all in `vercel-labs/agent-browser`: closed issue #1113, merged PR #1137, closed regression #1148, and open follow-ups #1371 and #1607. It is not a live feed or complete history. A merged fix and closed seed do not prove that related follow-ups are resolved.

## Evidence, not a merge gate

Shared files, closing relationships, and review states help decide what to inspect. They do not prove that two fixes are duplicates, an issue is resolved, or a PR is ready to merge. Graphs are bounded, inaccessible references remain uncertain, and status reports incomplete coverage explicitly.

The CLI does not mutate GitHub. Graph and reconcile commands save local snapshots by default; status saves only with `--save`, and plan does not save snapshots. Exports and agent prompts can include private metadata. Read the [security guidance](/docs/security) before sharing them.
